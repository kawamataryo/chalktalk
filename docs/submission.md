# 提出用：プロジェクト概要

Built with Claude: Japan 2026 の提出フォームに貼る文章。テーマ・審査の観点（インパクト／デモ／Claude の活用／深さと実行）に沿って書いている。

## プロジェクト名

**ChalkTalk**（チョークトーク）— 話しかければ、そばに先生。一人で勉強する子どものそばにいる、声で話せる先生

Talk は声で話すこと、Chalk は黒板のこと。

## ひとことで

共働きで親が手を離せない朝や夕方、iPad の向こうの先生が子どもの勉強を見守り、声で話しかけ、わからないところは**答えを言わずに、ヒントと図で**導く家庭学習アプリ。

## テーマとの関係

両方のテーマにまたがる。

- **テーマ1「あなたにしかない深さを」**：作者は共働きで、小5の長男が公立中高一貫校の受検勉強をしている。勉強に使える時間はあるのに、その時間に親は仕事と家事で見てあげられない。「一人で勉強するのは孤独」という、家庭の中にいる人にしか見えない課題から出発した
- **テーマ2「本来、誰にでも届くべきものを」**：家庭教師は、費用と時間に余裕のある家庭にしか届かない。答えを教えるのではなく「考えさせる」伴走を、どの家庭にも届ける

## 何ができるか

| | |
| --- | --- |
| 声だけで話せる | キーボードは使わない。学習中は先生が聞いていて、「ねえ先生」で話しかけられる。先生が話している途中でも「待って」と割り込める |
| 「これ見て」で問題を見せる | iPad のカメラで撮影。Claude が問題を読み取り、**答えは言わずに**「何を聞かれている？ → どこを見る？ → 考え方 → 一緒にたどる」の段階でヒントを出す。最後のひと言は子どもに言わせる |
| 図で説明する | 撮影した問題でも、会話の途中（「もとにする量ってなに？」）でも、黒板に図を出す。手順カード・線分図・面積図・数直線・割合の帯図・ベン図・時間の流れ・表・グラフの11種類（Generative UI）。話に合わせて1つずつ見せ、図にも答えは書かない（答えの部分は「？」） |
| そばにいる先生 | オリジナルのボクセル風の先生が、うなずき・考え中・ほめる・励ますなどの表情で反応し、声に合わせて口が動く。子どもが自分で解けたら、すぐに「すごいじゃん！」と喜ぶ |
| 時間の声かけ | 集中25分＋休憩5分。休憩中は雑談もできる |
| 覚えている | 前回の内容や好きなことを覚えていて、「昨日の割合の続きやる？」と始める。終わりにはその日のがんばりを具体的にほめる |
| 親が見られる | 親はスマホのブラウザで学習時間・取り組んだ問題・先生のひとことを見られる。深刻な悩みの兆しは「要確認」として親に残る |

## Claude の活用

- **役割で使い分けた2つの Claude と判断専用のモデル**
  - `claude-haiku-5-5`：会話。文ごとにストリーミングして、すぐに読み上げに流す（考える処理を止め、実機で最初の一文まで約 0.8〜1.0 秒）
  - `claude-sonnet-5-5`：撮影した問題の読み取り・ヒントの段階づくり・図の生成、セッション終わりのふり返りと記憶の整理
- **strict tool use**：黒板の部品（JSON Schema）、問題分析、ふり返り、親への「要確認」をすべて型の決まったツールで受け取る
- **答えを言わない仕組み**：正答は「先生のメモ」に隠してプロンプトに入れ、話す前に `AnswerLeakGuard` で正答が含まれていないか検査する（全角半角・漢数字・分数・単位の言い換えまで）
- **安全ルール**：個人情報を聞かない、ときどき親につなげる、深刻な兆候はツールで親に残す。評価スクリプト（`evals/run.mjs`）で本番の Claude に対して確認した
- **速い判断は Jev（TypeSafe AI の Decision API）**：「先生に話しかけたか」「言い終わったか」「撮影の依頼か」を、文章を作らない判断専用のモデルで決める（実機で 1 回 約 150〜200 ms。使えないときは規則で判断する）
- **開発そのものも Claude Code**：仕様書と issue を作り、サブエージェントを並行させ、worktree ごとに実装 → テスト → PR → マージを回した（iOS 400 件超・Worker 70 件超のテスト）

## 深さと実行

- **図の質を本番で測って直した**：適性検査風のオリジナル10問で、本番の Sonnet に図を作らせ、アプリの黒板で描いて確かめた。改善前は図が出たのが 0/10 → 改善後 10/10。表に逃げる割合も 6/10 → 2/10、図に答えが書かれたのは 0/10（[評価の記録](boards-eval.md)）
- **本番でしか出ない不具合を見つけた**：黒板のツールを strict な JSON Schema にすると、本番の API が「grammar が大きすぎる」と拒否していた（モックのテストでは通る）。strict をやめ、スキーマの既定値で欠けを補う方式にした

- iPad の実機で、日本語の端末内音声認識（SpeechTranscriber）とエコーキャンセルを自動検証してから設計を決めた（先生の声の混入：エコーキャンセルなし 34% → あり 0%）
- 会話の割り込み（GPT Live のような体験）を Claude で再現：割り込まれたら読み上げと Claude のストリームを止め、**実際に話したところまで**会話の履歴を切り詰める
- 子どもの写真と音声はどこにも保存しない。残すのは文字の要約だけ
- 構成：SwiftUI（iOS 26）＋ RealityKit ＋ Speech ＋ AVAudioEngine、Cloudflare Workers ＋ D1、ElevenLabs（読み上げ）
