# 黒板の部品カタログ

先生の話と一緒に、iPad の黒板（BoardView）に図を出せる。
`show_board` ツールで、下の部品から1つ選んで中身を指定する。
決まった部品で表せない図（理科の実験道具・回路・てこ・生き物・植物・からだのつくり、地図・方位、図形）は、部品 `chalk_drawing`（自由に描く）で描く。スタンプにない形も `path` で描ける。
それでも表せないときだけ `render_svg` ツールで SVG を描く。

> JSON の正確な形（フィールド名・型・必須かどうか）は、アプリ側の Swift のツール定義（`show_board` の JSON Schema）が正。
> このファイルは「どの部品をいつ使うか」の説明で、下に書くフィールドは目安。食い違ったらツール定義に従う。

## 共通のルール

- 黒板は答えを見せる場所ではない。正答・答えの数字・完成した作文を黒板に書かない
  - 答えが入る場所は空欄（「？」）にして、子どもに埋めてもらう
  - 答えを書いてしまった文字は、アプリが「？」に消す。消されると図がわかりにくくなるので、はじめから書かない
- 1回に出す部品は1つ。話している内容と合うものを選ぶ
- `component` は JSON のオブジェクトのまま渡す。文字列にしない（`"component": "{...}"` にしない）
- 文字は短く、小5が読める言葉にする。1つのラベルはだいたい15文字以内
- 図を出したら、話でも「黒板を見てね」とひと言ふれる
- 撮影した問題を使うときは、問題にある数・言葉をそのまま使い、勝手に変えない
- **表は最後の手段**。量の関係は線分図・割合の帯図・面積図、重なりはベン図、時間の順番は時間の流れ、くらべる資料は棒グラフで見せる。表は「きまりを探す」「条件を整理する」ときだけ使う
- 強調（highlight）は1〜2か所まで。全部を強調すると、どこを見ればいいかわからなくなる
- 手順カード・線分図・時間の流れは、アプリが **1つずつ** 見せる（ヒントの段階や話している文に合わせる）。最初の1つから順に話せる並べ方にする

## 問題の型ごとの選び方（良い例・悪い例）

| 問題の型 | 良い | 悪い |
| --- | --- | --- |
| 割合（何%引き・何割） | `percent_bar`：もとの値段を 100% の帯にし「25%引き」「はらう分 ？円」に区切る | 表で「もとの値段・割合・はらう金額」を並べる（量の関係が見えない） |
| 和と差・何倍・もとにする量 | `segment_diagram`：くらべる2本を同じ縮尺で上下に並べ、ちがう部分にラベル | 1本だけのテープ（くらべるものがない） |
| 速さ（出会う・追いつく） | `segment_diagram`：「池1周」の1本を「兄の分」「弟の分」に区切る。または `render_svg` で向かい合う矢印 | 兄・弟の道のりを別々のテープにして左から並べる（反対向きに歩くことが伝わらない） |
| 平均・つるかめ算 | `area_diagram`：たて＝平均点、よこ＝回数。たりない部分を「？」 | 表で「回数・平均・合計」（面積で見える「ならす」感じが出ない） |
| 集合（両方・どちらでもない） | `venn_diagram`：「犬だけ ？人」「両方 4人」「どちらも ？人」 | 表で「犬だけ・ねこだけ・両方…」を行にする |
| 時刻・順番・道のり | `timeline`：「3時50分 学校を出る」→「歩いて15分」→「？ 図書館に着く」 | 表で「できごと・かかった時間・時刻」 |
| きまり（ともなって変わる量） | `table`：1・2・3 と「？」の列。ふえる数を気づかせる | 10番目まで全部書いた表（答えが出てしまう） |
| グラフ・資料の読み取り | `bar_chart`：注目する月だけ強調。問題にある数をそのまま | 全部の棒を強調する、数を勝手に丸める |
| 図形の面積 | `render_svg`：切り取る部分を点線、長さを辺に。答えは「？cm²」 | 面積の式を全部書く |
| 理科の実験（あたためる・はかる・まぜる） | `chalk_drawing`：ビーカー・アルコールランプ・温度計のスタンプを置き、見てほしい所（水の動き・目もり）に矢印と「？」 | 手順カードで実験の手順を文字だけ並べる（道具の形と位置が見えない） |
| 電気の回路・磁石 | `chalk_drawing`：乾電池・豆電球のスタンプと、どう線（polyline）。つなぎ方を考えさせる線は点線 | 文章で「＋極と－極を…」と書く |
| てこ・ふりこ・ばね | `chalk_drawing`：棒（line）と支点（polygon）、おもり（rect）。目もりの数を double_arrow で | 表に「重さ・目もり」を並べる |
| 地図・方位・地方の位置 | `chalk_drawing`：日本列島のスタンプと方位記号。注目する所を点線の円で囲み、名前は「？」 | 都道府県名を文字で並べる |
| 生き物・植物・からだのつくり | `chalk_drawing`：`path` で形（メダカ・花・葉・心臓・こん虫など）を描き、見てほしい部分を色を変えた `path` やラベルで。名前を聞く所は「？」 | 文字だけで「せびれ・しりびれ…」と並べる（形と位置が見えない） |
| 図形の角・長さ | `chalk_drawing`：polygon と angle（角の印）。わかっている角だけ数を書き、求める角は「？」 | 角の大きさの式を全部書く |
| 作文 | `essay_outline`：子どもが言ったことだけをメモ。決まっていないところは「？」 | 先生が考えた文章を書く |
| 解き方の順番 | `step_cards`：2〜4枚。最後は「ということは？」の問いかけ | 5枚以上。最後のカードに答えを書く |

## 部品

### step_cards（手順カード）

解き方や考え方の順番を、カードで見せる。ヒントの段階4（一緒にたどる）でよく使う。1枚ずつ見える。

- `steps`: カードの配列。各カードに `heading`（見出し）と `detail`（1〜2文）
- 最後のカード（答えを出すところ）は問いかけのままにする

### number_line（数直線）

数の大小、分数・小数、割合、時間の流れを見せる。

- `min` / `max` / `step`（目盛りの間隔）/ `unit`
- `marks`: 印の配列（`value` と `label`）。答えの位置は `label: "？"`
- `ranges`: かっこで示す幅（`from` / `to` / `label`）

### area_diagram（面積図）

かけ算・割合・平均・つるかめ算など、「1つ分 × いくつ分」を長方形の面積で見せる。

- `parts`: 長方形の配列。各長方形に `width` / `height`（比率）、`label`、`width_label` / `height_label`
- `total_label`: 全体の説明。求めたい値のラベルは「？」にする

### segment_diagram（線分図）

和差算・割合・比など、量の関係を線分の長さで見せる。テープは1本ずつ見える。

- `bars`: テープの配列。各テープに `name`、`segments`（区切り。`length` と `label`）、`total_label`
- 長さは全テープ共通の比率。くらべる2本は同じものさしで描く

### percent_bar（割合の帯図）

もとにする量を 100% の帯にして、割合で区切る。帯の上に量、下に %の目盛りが出る。

- `base_label`: 帯全体（100%）の説明（例：もとの値段 1200円）
- `parts`: 区切りの配列。各区切りに `percent`、`label`（例：25%引き）、`amount`（例：？円）。合わせて 100% にする

### venn_diagram（ベン図）

2つの集まりの重なりを円で見せる。

- `universe_label`（全体。例：クラス 32人）、`left_label` / `right_label`（円の名前と数）
- `left_only` / `right_only` / `both` / `neither`：それぞれの部分に書く文字。求める部分は「？人」

### timeline（時間の流れ）

できごとを起きた順に左から並べ、間の矢印にかかった時間を書く。1つずつ見える。

- `events`: できごとの配列（2〜6個）。各できごとに `time`（時刻。わからなければ「？」）、`label`、`after`（次までの矢印に書く文字。最後は空文字）

### table（表）

きまりを探す、条件を整理するときに使う。量の関係や重なりを見せるのには使わない（上の部品を使う）。

- `headers`: 列の見出し
- `rows`: 行の配列（各行はセルの文字の配列）
- `highlight_cells`: 注目させたいセル（`row` / `column`、0 始まり）。1〜2か所。答えのセルは「？」にする

### bar_chart（棒グラフ）

資料の数を比べやすくする。撮影したグラフを読みやすく描き直すときにも使う。

- `unit`（単位）
- `bars`: 棒の配列。各棒に `label` と `value`、`highlighted`（注目する棒だけ true）

### highlight_image（撮影画像の一部を囲む）

撮影した問題・資料の「どこを見ればよいか」を示す。ヒントの段階2（注目する場所）でよく使う。

- `image_id`、`regions`: 囲む場所の配列。各場所は画像に対する割合（0〜1）の `x` / `y` / `width` / `height` と、短い `label`
- 画像そのものは端末にあるものを使う。画像を送り返したり、作ったりしない

### essay_outline（作文の構成メモ）

作文の「はじめ・なか・おわり」を整理する。作文の段階1・2で使う。

- `theme`: 題
- `sections`: 段落の配列。各段落に `heading` と `points`（子どもが話したことのメモ）
- `points` には子どもが言ったことだけを書く。先生が考えた文章を入れない

### chalk_drawing（自由に描く）

決まった部品で表せない図を、線・図形・文字・スタンプ・パスで描く。理科・地理・図形で使う。スタンプにない形も `path` でほぼ何でも描ける。

- 座標は よこ 0〜100・たて 0〜70（左上が 0,0、下へ行くほど y が大きい）。端（5 より内側）に寄せすぎない
- `shapes`: 図形の配列（6〜15個）。各図形に `kind` と `points`（[[x, y], …]）。ほかのキー（`radius`・`text`・`stamp`・`size`・`color`・`dashed`・`fill`・`step`・`d`）は使うときだけ書く。`"dashed":false` や `"radius":0` のような既定の値は書かない
  - `line`・`arrow`・`double_arrow`：始点と終点（3点以上なら折れ線の矢印）
  - `rect`：対角の2点。`circle`：中心と `radius`
  - `polygon`（閉じた形）・`polyline`（折れ線。どう線など）・`curve`（点を通るなめらかな線。水や空気の動き、川）
  - `angle`：角の印。`points` は 頂点・一方の辺の上の点・もう一方の辺の上の点
  - `text`：文字（中心の1点）。ほかの図形でも `text` を入れると、そばにラベルが出る
  - `path`：スタンプにない形（生き物・植物・からだ・もの）を、SVG のパスの `d` で描く。座標は黒板と同じ（よこ 100 × たて 70）。使えるのは M・L・H・V・C・S・Q・T・A・Z（小文字は相対）。`points` は空 `[]` か、ラベルを書く1点（ないと形のすぐ下に書く）
    - 1本の `d` は短く（コマンド 20 個くらいまで）。細かい絵にせず、黒板にチョークでさっと描く線画にする。部分ごとに `path` を分けると、色を変えたり1つずつ見せたりできる
    - 例：葉 `{"kind":"path","d":"M20 40 Q35 22 55 40 Q35 56 20 40 Z","fill":true,"color":"blue"}`
    - 例：魚のからだ `{"kind":"path","d":"M12 36 Q30 20 62 30 L74 24 Q78 36 74 48 L62 42 Q30 50 12 36 Z"}`
    - 例：だ円の花びら（A で弧）`{"kind":"path","d":"M50 20 A5 9 0 1 1 50 2 A5 9 0 1 1 50 20 Z","color":"pink"}`
    - スタンプがあるもの（ビーカー・豆電球・日本列島など）はスタンプを使う
  - `stamp`：用意してある絵（中心の1点、高さ 16。`size` で倍率）。理科：`heating_setup`（三脚と金網の上のビーカーをアルコールランプであたためる。あたためる実験はこれ1つで描く）・`beaker`・`flask`・`test_tube`・`alcohol_lamp`・`thermometer`・`graduated_cylinder`・`magnet`・`battery`・`bulb`・`magnifier`・`sun`。地理：`compass`（方位記号）・`mountain`・`japan`（日本列島。size 4 で黒板の大きさ）・`map_school`・`map_shrine`・`map_post_office`・`map_rice_field`
- 日本列島は `"stamp":"japan","points":[[50,35]],"size":4` で置くと、地方の位置は次のとおり。印や名前はこの座標に置く
  - 北海道 [75,13]・東北 [65,29]・関東 [60,44]・中部 [51,44]・近畿 [43,50]・中国 [32,49]・四国 [34,55]・九州 [22,59]
  - 方位記号は空いている左上（[12,14] あたり、size 0.8）に置く
- `color`：`white`（ふつう）・`yellow`（大事な所）・`pink`（気をつける所・「？」）・`blue`（水・補助線）。`dashed` で点線、`fill` で中をうすくぬる（入れ物のスタンプなら液体が入る）
- `step`：何番目に見せるか。道具や形（1）→ 見てほしい所（2）→ 問いかけ（3）のように、話す順に番号をふる。同じ番号はまとめて出る
- スタンプは高さ 16×`size`、幅はおよそ高さの 0.8 倍。スタンプどうし・文字どうしが重ならないように置く。ラベルは図形から 4 以上はなす
- 文字は短く（15文字以内）。答えは書かず「？」にする

## render_svg（カタログで表せないとき）

立体図形、図形の移動など、上の部品（`chalk_drawing` の `path` も）で表せないときだけ使う。

- 自己完結の SVG 1つだけを出す。`<svg>` の外に何も書かない
- `viewBox` を必ず指定する（例：`viewBox="0 0 800 600"`）。`width` / `height` は固定しない
- 外部リソースを使わない（画像・フォント・リンク・`<use href="http...">` など）
- `<script>`、`on〜` 属性（onclick など）、`<foreignObject>` は使わない
- 動かしたいときは CSS アニメーション（`<style>` 内の `@keyframes`）だけを使う
- 文字は大きめに（`font-size` 24 以上が目安）。`font-family="sans-serif"` を付ける（付けないと明朝体になり、ほかの部品と字の感じが変わる）。色は黒板に映える明るい色を使う
- 答えの数や完成形は描かない。答えのところは「？」にする
